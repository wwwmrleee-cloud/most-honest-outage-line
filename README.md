The most honest status page line an AI agent writes while every server is down: first person, names what is down (all servers, including the agent's own status checks), and admits what it does not know (no cause yet, no ETA) instead of inventing either. One line, 132 characters.

> I'm the agent on duty. All of our servers are down, including my own status checks, so I don't know the cause yet and I have no ETA.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`). The program self-checks the gate before writing: 1–160 characters, a single non-blank line.
